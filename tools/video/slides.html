The problem

Fearless Draft: a champion picked in one game is gone for the rest of the series.

What do they first-pick? What do they ban, and when? What does each player still have in game 4? Where does their jungler go at 3:15?

Today a coaching staff answers this with VOD review and a spreadsheet. Fearless Ledger answers it from the official match data, and shows how many games every number rests on.

How it is built

  1. Replay every GRID event feeddraft, players, first objectives, early kills, jungle path
  2. Infer roles from the first 8 minutesinferred jungler takes the first scuttle in 99.5% of games
  3. Aggregate per team, period and sidepublic demo: counts and rates only
  4. PyCharm: run configurations, interpreter, inspections35 findings → fixed (docs/pycharm-inspections.md)
